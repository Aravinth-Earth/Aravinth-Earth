Splitter

Shared group expenses, sealed in your browser.

One person creates a group and passes on a 16-character code; everyone else opens the same group with it. Expenses land on every screen as they are added, and at the end the app shows who owes whom.

Open Splitter Use the local-only version

Splitter is still in development, so small things may change.

How it works

  1. Create a group and get a code
  2. Everyone adds what they paid
  3. See who owes whom, and settle up

What the server can and cannot do

The code is the key, and it never leaves your browser. The server holds ciphertext and the routing ids that let your devices find each other — not names, amounts or splits.

  • A leaked code cannot be revoked. Anyone who has it can open the group, and there is no way to call it back.
  • The server cannot check a split. It cannot read the amounts, so it cannot tell you that they add up. That check stays with you.
