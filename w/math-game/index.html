How the Game Works

Scoring System

  • Base Scores: Easy (10), Medium (20), Hard (30), Expert (40)
  • Streak Bonus: Every 3 correct answers (+5 points)
  • Maximum Streak Multiplier: 10x
  • Difficulty Bonus: Based on current complexity level

Difficulty Progression

  • Skill Rating: Starts at 1000, caps at 4000
  • Complexity: Increases with skill and streak
  • Maximum Difficulty: 50
  • Number Ranges: Scale logarithmically with difficulty

Performance Tracking

  • Success Rate: Based on correct vs total attempts
  • Skill Rating: ELO-like system that adapts to performance
  • Recent Performance: Affects difficulty adjustments
