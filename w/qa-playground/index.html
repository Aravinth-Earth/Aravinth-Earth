QA Playground

A collection of web elements and interaction patterns for testing automation skills. Pick any page to practice with Selenium, Cypress, Playwright, or any automation framework.

Tracks, not levels. Every page is tagged with the skill it drills — finding, driving, waiting, faking, or proving. No seniority ladder and no year counts: those five problems outlive any framework, and they don't care whether a human or an agent writes the test.

Aether Store — a whole app Show your work

A separate, complete marketplace: real company valuations, a fictional currency, a wallet, a checkout and a portfolio — every flow on one site.

Practice: end-to-end journeys (sign up → top up → buy → portfolio → cancel → delete), money maths, quote expiry, insufficient balance, idempotent submits.

Accounts — real API Trust nothing

Not a mock: signup, login, MFA, expired reset and delete against a live Worker + D1 that forgets you in 24 hours.

Practice: real HTTP status codes (201/401/409/423/429), duplicate email, wrong-password attempt counting, lockout, MFA ticket, password reset, bearer sessions, delete-and-reuse-the-email.

Input Fields Handle with care

Type, poke, get rejected: maxlength, readonly, disabled, and a file picker.

Practice: locating text/number/email/password inputs, file upload, and negative tests for maxlength/readonly/disabled/hidden fields.

Selection Elements Handle with care

Ticks and dropdowns that quietly remember what you did.

Practice: checkboxes, radios, single/multi-select, optgroup, and reading selected values.

Interactive Elements Handle with care

Dialogs that argue back, toasts that vanish, menus that open only on hover.

Practice: modals, browser alerts/confirm/prompt, tooltips, hover menus, toasts, accordions.

Forms & Validation Handle with care

One form, a dozen ways to be wrong.

Practice: required fields, field-level validation, success/error submission states.

Upload & Drag & Drop Handle with care

A file that has to arrive by drag, not by picker.

Practice: file uploads, drag-and-drop (native events), type/size validation.

Frames & Windows Say my name

Elements living inside elements — your selector can't see them yet.

Practice: switching iframes, nested frames, new windows/tabs, popups.

Shadow DOM Say my name

The element exists. A normal CSS selector will never reach it.

Practice: querying across shadow roots and framework-specific shadow handling.

Dynamic Content Beat the clock

It shows up late, sometimes twice, sometimes never.

Practice: implicit/explicit waits, stale elements, spinners, progress bars, lazy loading.

Mock API Trust nothing

The server lies on purpose. Test both lies.

Practice: waiting, error handling, and request interception (cy.intercept / page.route).

Web Storage Trust nothing

State that survives a reload — and tests that must not.

Practice: reading/writing storage and building test isolation around it.

Data Tables Show your work

Sort it, page it, delete a row — then prove the data really moved.

Practice: sorting, filtering, pagination, dynamic rows, empty/max/random states.

Downloads Show your work

A file that only exists after the click.

Practice: verifying download filenames, content, and download events.

Accessibility Audit Show your work

Defects hiding in plain sight. Your eyes won't find them; the keyboard will.

Practice: a11y auditing, semantic HTML, keyboard access, ARIA.
